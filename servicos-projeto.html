Projetos

Desenvolvemos projetos de arquitetura de interiores com foco em funcionalidade, estética e praticidade. Atendemos de forma online, com processos claros e soluções personalizadas para cada necessidade.

Mini

Um ambiente, uma transformação completa.

Para quem quer transformar um único ambiente ou começar por uma parte da casa, com soluções pensadas para aproveitar melhor o espaço.

O que está incluso

  • Layout e aproveitamento do espaço
  • Conceito, cores e materiais
  • Imagens 3D do ambiente
  • Projeto executivo
  • Orientações para mobiliário, iluminação e decoração
  • Lista de itens e produtos sugeridos
  • Revisões ilimitadas por etapa

Não incluso

  • Outros ambientes
  • Estimativa de custo
  • Orçamentos

Mais escolhido

Essencial

O projeto para transformar a ideia em obra.

Para quem quer um projeto completo de interiores com as informações necessárias para executar a reforma, incluindo o detalhamento de marcenaria dos ambientes definidos no escopo.

O que está incluso

  • Projeto de interiores dos ambientes contratados
  • Layout
  • Conceito, cores e materiais
  • Imagens 3D para visualizar o resultado
  • Projeto executivo
  • Detalhamento de marcenaria dos ambientes previstos
  • Memorial e especificações principais
  • Revisões ilimitadas por etapa

Não incluso

  • Estimativa de custo
  • Orçamentos
Quero o Essencial

Completo

Do projeto à preparação para a execução.

Para quem quer ter o projeto totalmente desenvolvido, com todos os ambientes detalhados e as informações e valores necessários para avançar com segurança para a obra.

O que está incluso

  • Tudo o que o Essencial inclui
  • Detalhamento completo de marcenaria
  • Detalhamento dos ambientes e elementos necessários à execução
  • Especificações completas de materiais e acabamentos
  • Compatibilização das informações do projeto
  • Estimativa de custo da obra
  • Orçamentos com fornecedores
Quero o Completo

Personalizado

O projeto na medida do que você precisa.

Para projetos que pedem uma combinação específica de ambientes, etapas ou entregas. Definimos juntos o escopo ideal para o seu espaço.

O que está incluso

  • Escopo definido de acordo com suas necessidades
  • Ambientes e nível de detalhamento personalizados
  • Soluções de interiores sob medida
  • Entregas definidas na proposta
  • Número de revisões conforme o escopo

Ideal para: quem precisa de algo entre as modalidades ou de uma solução específica.

Basta entrar em contato pelo WhatsApp ou pelo formulário do site. Enviamos o nosso Questionário de Projeto para entender suas necessidades e, em seguida, agendamos uma conversa inicial para alinhar expectativas e enviar uma proposta personalizada.

O Mini é para transformar um único ambiente, com layout, conceito, imagens 3D e projeto executivo. O Essencial é o projeto de interiores dos ambientes contratados, com detalhamento de marcenaria e memorial, pronto para a reforma. O Completo inclui tudo o que o Essencial tem e vai além: detalhamento completo, compatibilização, estimativa de custo da obra e orçamentos com fornecedores.

Para isso existe o Personalizado: definimos juntos os ambientes, o nível de detalhamento, as entregas e o número de revisões, tudo descrito na proposta. É ideal para quem precisa de algo entre as modalidades ou de uma solução específica.

No Mini, no Essencial e no Completo, as revisões são ilimitadas dentro de cada etapa: você ajusta o que precisar antes de avançarmos para a próxima. No Personalizado, o número de revisões é definido conforme o escopo.
